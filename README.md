# South Leicester Birdwatchers

Custom WordPress development for the South Leicester Birdwatchers website.

- [Local development and migration notes](LOCAL-DEVELOPMENT.md)
- [Trip bird lists feature specification](docs/trip-bird-lists-specification.md)

The existing Local installation lives in `app/public`. Start the site in Local
and visit http://southleicesterbirdwatchers.local.

This repository tracks project source rather than a complete WordPress backup.
Production releases should contain only the relevant custom plugin directory,
packaged as an installable ZIP. Do not deploy the local database, credentials,
or development safeguards.
